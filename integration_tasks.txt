## ✅ PHASE 1: AUTHENTICATION (COMPLETED)

### 1.1 Auth Endpoints
- [x] POST /auth/login — Farmer login (phone + password)
- [x] POST /org/auth/login — Organization login (email + password)
- [x] POST /auth/register — General user registration
- [x] POST /auth/register/farmer — Farmer registration (name, email, phone, national_id, land_size, crops_type, address_village)
- [x] POST /auth/register/factory — Factory registration (name, email, phone, national_id, factory_owner_name, industrial_registration_number, industry_type, address_village)
- [x] POST /auth/google — Google social login
- [x] GET /auth/profile — Get authenticated user profile
- [x] POST /auth/logout — Logout user

### 1.2 Auth Service Layer
- [x] AuthService class with all auth methods (loginFarmer, loginOrg, register, registerFarmer, registerFactory, loginWithGoogle, getProfile, logout)
- [x] AuthResponse model with token + user parsing
- [x] Error handling with Either (Left for errors, Right for success)
- [x] Token persistence via LocalStorageService (save, get, clear)

### 1.3 Auth UI
- [x] Login page with role toggle (farmer / organization)
- [x] Register page with role toggle (farmer / factory)
- [x] Dynamic form fields per role (land size / crops type for farmer, industry type / industrial reg number for factory)
- [x] Validation per role
- [x] Auto-login if token exists (main.dart)
